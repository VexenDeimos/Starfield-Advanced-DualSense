## Scope

v0.3.69 promotes only the hardware-proven missile-launch identity from v0.3.68:

- exact Wwise event: `0x6846C9EC`;
- launcher game object learned dynamically per firing stream; the observed `0x11E` is not hardcoded;
- first native launch post may precede physical R2 by roughly 75-107 ms, handled by the same bounded 180 ms forward-correlation model;
- later launches require the same event, the same learned Wwise game object, and held physical R2;
- the observed held-fire cadence of roughly 1.003-1.033 seconds remains native Wwise cadence only. No synthetic timer/RPM is generated.

The following v0.3.68 one-off/secondary events remain non-authoritative: `0xF815B476`, `0xD6EA60CA`, `0x26DC4340`, `0x1A786F20`, and `0x9D27996A`.

Accepted prior ship families remain frozen: ballistic v0.3.63-r6, pulse laser v0.3.65-r2, and Proton Beam particle v0.3.67.

## Controller feel

Each confirmed missile launch produces exactly one 105 ms `ShipMissileLaunchThump` at 0.90 base gain. The shape is intentionally the heaviest ship-weapon transient so far: a hard ignition kick followed by a short low-frequency rocket/motor tail. It layers over normal propulsion and does not create a continuous missile vibration while R2 is merely held.

R2 receives one finite 105 ms heavy `EffectEx` launch break per confirmed native launch. The break is stronger and lower-frequency than the accepted ballistic snap, then the generic cockpit resistance wall returns between launches.

## Focused hardware test

Use the same single missile launcher group on W0/R2 used for v0.3.68 recon.

1. Enter pilot context and let propulsion settle for about two seconds.
2. Fire two or three single missiles, pausing briefly between them.
3. Hold R2 for about three seconds so multiple native launch heartbeats can occur.
4. Release for about one second, then hold again for about three seconds.
5. If practical, fire one missile with a valid target lock.
6. Open DataMenu, wait briefly, close it, then fire a final one- or two-second burst.
7. Release R2 and wait about one second before ending the capture.

Expected feel: one strong `KTHOOM`-style body/trigger transient per actual launch, normal propulsion underneath, and no continuous missile buzz between native launches.
