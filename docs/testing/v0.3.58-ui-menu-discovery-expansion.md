# v0.3.58 UI Menu Discovery Expansion

v0.3.58 is a bounded diagnostic follow-up to the accepted v0.3.57 UI/scanner speaker path. It does **not** add new production UI sounds yet. The existing five promoted cues remain unchanged:

- `UIMenuGeneralFocus` (`0x05234A32`)
- `UIMenuGeneralOK` (`0x5C8034FC`)
- `UIMenuGeneralCancel` (`0x7956E9B0`)
- `UIMenuMonocleOpen` (`0x12D8B183`)
- `UIMenuMonocleClose` (`0x1F770B61`)

The scanner open/close pair is hardware-accepted and frozen. v0.3.58 re-enables the existing bounded 120-second menu discovery plus 60-second HUD follow-up, but the discovery probe rejects those five already-promoted event IDs so the log is focused on missing UI/HUD candidates. Discovery requires `DebugLogging = true`; it is diagnostic-only and remains independent of `SpeakerScannerUI` so disabling controller-speaker UI playback does not change what can be observed diagnostically.

## Hardware discovery run

Keep `DebugLogging = true`. For normal playback validation, also keep `ControllerSpeaker = true` and `SpeakerScannerUI = true`.

1. Launch Starfield and confirm the log reports `0.3.58-ui-menu-discovery-expansion`.
2. Confirm `UI audio discovery: ACTIVE ... unpromotedOnly=yes existingPromotedPlayback=5`.
3. Confirm the five readiness lines show real quoted Wwise names rather than the old literal formatting text.
4. Open the Data menu to start the bounded discovery session.
5. During the next 120 seconds, deliberately exercise as many UI actions as practical: Inventory categories/items, Skills, Powers, Missions, Galaxy/Surface Map, Status/Almanac, ship editor/crew screens, tab/category changes, focus changes, confirm/back, and any obvious UI transitions whose sound is not yet mirrored to the controller.
6. Verify the existing focus/OK/cancel controller sounds still work normally while discovery is active.
7. Open and close the scanner and confirm its accepted controller-speaker sounds remain unchanged.
8. Close qualifying menus and allow the 60-second HUD follow-up to finish if practical; exercise normal HUD notifications or UI beeps during that interval.
9. Exit normally and return the fresh `StarfieldDualSense(...).log`.

No WEM ZIP is required for this pass. The next promotion pass will select and resolve the useful unpromoted event IDs from the log rather than guessing.
