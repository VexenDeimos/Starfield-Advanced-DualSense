# v0.3.62 Propulsion Haptics Hardware Gate

## Scope

This is the first real ship haptics candidate. It adds only continuous propulsion feel:

- subtle cockpit/engine idle while the player owns the pilot context;
- throttle texture driven by native effective throttle (`+0x6C`);
- velocity-informed body driven by the native velocity lane (`+0x70`), including throttle-zero coast;
- a separate, materially heavier boost texture gated by native boost throttle plus spent `SpaceshipBoostFuel`;
- per-sample smoothing for ordinary throttle/velocity updates;
- immediate exact-silence clear on loading invalidation or pilot exit.

It deliberately does **not** add ship weapons, ship damage, controller-speaker cues, adaptive triggers, ship lightbar, targeting, docking, or grav-jump presentation.

Expected DLL version: `0.3.62.0 / 0.3.62.0`  
Expected runtime marker: `0.3.62-propulsion-haptics`

## Windows gate

Run the supplied v0.3.62 propulsion-haptics Windows gate. It must pass the new mapper/waveform and ownership tests plus the retained v0.3.61 lifecycle/ownership/consumer-safety gates, recoil, full haptics, sustained speaker, Auto-Rivet, and source regressions before installing the DLL.

## Hardware flight gate

Use one normal ship first so the feel can be tuned without mixing ship-build differences into the first acceptance run.

1. **On-foot reference**
   - Equip a known firearm such as Maelstrom.
   - Confirm the approved weapon trigger/haptic behavior before entering the ship.

2. **Pilot entry / stationary idle**
   - Enter the pilot seat and wait several seconds before applying thrust.
   - Expected: handheld weapon state clears; a very subtle continuous cockpit/engine texture begins only after a fresh ship-state sample.
   - Idle should be noticeable when concentrating on it, but should not feel like a weapon or a heavy rumble.

3. **Normal acceleration**
   - From near zero speed, increase normal forward thrust gradually to roughly half, then to full.
   - Expected: engine texture strengthens/rises smoothly with effective throttle; no 5 Hz stepping or abrupt amplitude jumps should be obvious.

4. **Steady cruise**
   - Hold a stable normal throttle for several seconds.
   - Expected: sustained texture remains stable rather than pulsing or retriggering.

5. **Coast**
   - Drop throttle to zero while still moving quickly.
   - Expected: engine-demand texture falls, but some low body remains while velocity is high. As velocity decays toward zero, the feel settles back toward idle.

6. **Boost**
   - From ordinary flight, trigger one normal boost for roughly 3-5 seconds.
   - Expected: boost becomes unmistakably heavier than full normal propulsion and follows the native boost session. It must stop being boost when native throttle leaves the boost range even though boost fuel is still recharging.

7. **Loading safety**
   - Trigger one travel/loading sequence while the cockpit survives the load if convenient.
   - Expected: loading INVALIDATE clears propulsion immediately; RESUME stays neutral until a fresh post-load propulsion sample, then propulsion returns without stale handheld state.

8. **Pilot exit**
   - Leave the pilot seat and return on foot.
   - Expected: ship haptics clear immediately and never continue on foot. Fresh on-foot weapon trigger/haptics and health lightbar return through the existing refresh path.

```text
Ship pilot context: EXIT ...
Ship pilot context: ON-FOOT-REFRESH ...
```

## Acceptance

Do not approve the slice if any of the following occur:

- idle is annoyingly strong;
- normal thrust feels like repeated pulses instead of one smooth sustained engine texture;
- coast goes completely dead at high speed or incorrectly feels like full thrust;
- boost is not clearly stronger than full normal propulsion;
- boost persists through recharge after native boost has ended;
- any ship haptic survives LoadingMenu invalidation or pilot exit;
- handheld weapon haptics/triggers/speaker state leak into pilot context;
- on-foot weapon/lightbar reconstruction fails after exit;
- any previously approved weapon, melee, UI/speaker, Starstorm, Cutter, Arc Welder, Auto-Rivet, or Magsniper behavior changes.
