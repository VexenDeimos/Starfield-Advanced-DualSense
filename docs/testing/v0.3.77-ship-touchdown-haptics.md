# v0.3.77 Ship Touchdown Haptics

v0.3.77 promotes only the hardware-verified landing state boundary to production haptic output. During an active cinematic landing sequence, the existing runtime-tick precision observer detects the fresh non-docked `landed=false -> landed=true` transition. That transition emits one normalized `ShipTouchdown` semantic at the exact state-read timestamp.

The haptic presentation is intentionally simple: one finite 100 ms `ShipTouchdownThump` at 0.90 base gain. It has a low-frequency impact body and a small structural knock, then returns to exact silence. There is no continuous landing rumble, adaptive-trigger effect, controller-speaker cue, or lightbar change.

Native Wwise event `0x456ED309` remains diagnostic corroboration only and is not production authority. The accepted takeoff reconnaissance, propulsion path, and ballistic/laser/particle/missile/EM ship-weapon behavior are otherwise unchanged.

## Windows gate

Run the supplied `StarfieldDualSense_v0.3.77_Ship_Touchdown_Haptics_Windows_Gate.ps1`. The installed DLL must report ProductVersion and FileVersion `0.3.77.0`, and runtime startup must include `0.3.77-ship-touchdown-haptics`.

## Hardware check

Start from any save, enter the pilot chair, take off, and perform one normal landing that plays the full third-person landing sequence. Let the cinematic finish naturally and remain seated for several seconds. You should feel one short heavy thump at touchdown and no rumble tail. The log should contain both the authoritative `boundary=touchdown` line and `Ship touchdown haptics: stage=submitted kind=ShipTouchdownThump` at the same state-read timestamp.
