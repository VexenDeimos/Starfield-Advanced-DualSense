# v0.3.49 Starstorm Sustained Body Tuning

## Scope

This release changes only the Va'ruun Starstorm sustained controller-speaker body's preparation gain from 0.35 to 0.80. Starstorm start/stop transients remain 0.35. Penumbra and every previously accepted weapon remain unchanged.
