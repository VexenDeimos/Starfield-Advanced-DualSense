# v0.3.51 Starstorm Sustained Body Loudness

## Scope

This build changes only the Va'ruun Starstorm persistent sustained-body media `963157375` from preparation gain `0.80` to `1.60` (approximately +6 dB). The v0.3.50 hardware diagnostic showed that the decoded left/right channels are strongly correlated, the mono downmix preserves the body, and the final DualSense Channel-2 output carries it correctly; the remaining issue is perceptual level.

All seven sustained-start accents, the immediate sustained-stop transient, PowerDown, reload/equip cues, authored `smpl` loop points, Wwise start/stop authority, Penumbra, Starlash, Arc Welder, Cutter, haptics, adaptive triggers, VO, and normal Starfield audio are unchanged.

The v0.3.50 Starstorm PCM/render diagnostics remain active for one more hardware validation build.
