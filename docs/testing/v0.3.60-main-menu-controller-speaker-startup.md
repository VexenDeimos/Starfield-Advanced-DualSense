# v0.3.60 Main Menu Controller Speaker Startup

## Scope

v0.3.60 makes the already-promoted generic UI controller-speaker cues available early enough for Starfield's title/main menu:

- `UIMenuGeneralFocus` (`0x05234A32`)
- `UIMenuGeneralOK` (`0x5C8034FC`)
- `UIMenuGeneralCancel` (`0x7956E9B0`)

The cue identities, game object (`0x3`), native cadence, PCM gain, controller-speaker routing, and `SpeakerScannerUI` / `ControllerSpeaker` gates are unchanged. No synthetic menu sounds are generated and Starfield's original Wwise `PostEvent` remains authoritative.

The only runtime change is startup timing: an isolated UI-only background prewarm begins from `SFSE_PLUGIN_LOAD`, before `kPostDataLoad`. It prepares only the three generic cues into the same atomic UI cache later reused by the production playback path. The normal post-data-load audio pipeline still prepares the full ten-cue catalog and all existing weapon/diagnostic work as before.

Install the DLL and verify both `ProductVersion` and `FileVersion` are `0.3.60.0`.

## Hardware acceptance

1. Keep `ControllerSpeaker = true` and `SpeakerScannerUI = true`.
2. Launch Starfield and stay on the title/main menu before loading a save.
3. Move through main-menu items repeatedly. The controller speaker should mirror Starfield's native generic focus sound on each real focus event.
4. Activate a main-menu item and exercise a back/cancel path where available. The generic OK/Cancel copies should follow Starfield's native event cadence.
5. Load a save and verify the existing in-game ten-cue UI/scanner coverage is unchanged, including scanner open/close.
6. Set `SpeakerScannerUI = false`, relaunch, and confirm both main-menu and in-game UI/scanner controller-speaker copies are disabled while normal Starfield audio remains present.
7. Restore the setting and perform a shutdown smoke test.

The log should show `Main-menu UI speaker prewarm: worker started` before post-data-load runtime initialization, followed by `Main-menu prewarm: UI speaker cue ready` lines for the three generic cues when preparation succeeds.
