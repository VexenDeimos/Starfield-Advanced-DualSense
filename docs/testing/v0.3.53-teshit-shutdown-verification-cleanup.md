# v0.3.53 TESHit Shutdown Verification Cleanup

v0.3.53 fixes only the shutdown verifier for the diagnostic TESHit event sink.

The v0.3.52 release-candidate smoke log showed a valid local removal:

- `sinksBeforeUnregister=8/8`
- `sinkPresentBefore=yes`
- `sinksAfter=7/8`
- `sinkPresentAfter=no`

but the old verifier still emitted `verification=FAIL` because it required the final source count to match the pre-registration count captured much earlier in the session. Another sink had legitimately registered in the meantime.

The v0.3.53 rule is local and exact:

1. StarfieldDualSense's exact sink is readable and present immediately before `UnregisterSink`.
2. The exact sink is readable and absent immediately afterward.
3. The source sink count drops by exactly one.

No TESHit registration or event-delivery behavior changes. No incoming-damage, melee, weapon-audio, adaptive-trigger, controller-speaker, VO, or normal-game-audio behavior changes.

## Focused runtime check

Start Starfield, load a save, exercise normal controller behavior briefly, then quit the game normally. In the fresh log, find the final `TESHit diagnostic: sink unregistered` line.

A healthy shutdown must show:

```text
sinkPresentBefore=yes ... sinkPresentAfter=no verification=PASS
```

The sink counts may differ from the old pre-registration count if unrelated sinks joined later; the only required count relationship is an exact one-entry drop across this unregistration call.
