# v0.3.56 Focused HUD/Scanner Candidate Resolution — Windows / Hardware Gate

v0.3.56 is diagnostic-only. It does **not** add UI/HUD controller-speaker playback. It retires the broad v0.3.55 menu/HUD runtime capture for this pass and resolves exactly three hardware-selected HUD/scanner Wwise event IDs through the existing background resolver.

## Expected invariants

- Active runtime UI candidate list contains exactly:
  - `0x12D8B183` (`scanner-12D8B183`)
  - `0x1F770B61` (`scanner-1F770B61`)
  - `0x06D80D5E` (`hud-06D80D5E`)
- The eight v0.3.55 menu candidates remain available only as retained historical test evidence.
- Broad UI discovery is inactive at runtime in v0.3.56. There is no new 120-second menu session and no 60-second broad HUD follow-up.
- Candidate resolution remains on the existing weapon-audio background worker; no second Wwise hook or game-thread archive scan is added.
- Resolved WEMs are written only under `Data/SFSE/Plugins/StarfieldDualSenseDiagnostics/v0.3.56/UiWemCandidates/`.
- No UI/HUD WEM is submitted to the controller speaker.
- Weapon audio, VO, haptics, adaptive triggers, lightbar, touchpad, HID arbitration, USB speaker mapping, TESHit behavior, and normal Starfield audio remain unchanged.

## Runtime resolution check

Before launching, it is okay to delete this folder if it exists from an earlier v0.3.56 run:

```text
Data\SFSE\Plugins\StarfieldDualSenseDiagnostics\v0.3.56\UiWemCandidates
```

Launch Starfield and load fully into a save. No menu choreography is needed in this build. Allow the normal background weapon/Wwise resolver to finish.

The log should contain exactly one `UI Wwise candidate resolver:` line for each active event:

```text
0x12D8B183
0x1F770B61
0x06D80D5E
```

Each successfully resolved event may produce one or more `UI Wwise candidate media:` lines. Successfully extracted WEMs should appear under the v0.3.56 `UiWemCandidates` folder and be listed in `manifest.tsv`. `not-found` or `found-no-media` is still useful diagnostic evidence and is not by itself a runtime failure.

The log should also report that broad UI discovery is inactive for the focused pass:

```text
UI audio discovery: INACTIVE reason=focused-v0.3.56-candidate-resolution broadCapture=no
```

After the resolver has settled, quit Starfield normally so shutdown diagnostics are captured.
