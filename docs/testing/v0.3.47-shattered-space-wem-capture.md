## Runtime capture

Before starting, optionally remove the old v0.3.47 capture directory if repeating the test:

```powershell
Remove-Item "C:\Games\Steam\steamapps\common\Starfield\Data\SFSE\Plugins\StarfieldDualSenseDiagnostics\v0.3.47\ShatteredSpaceWemCapture" -Recurse -Force -ErrorAction SilentlyContinue
```

In one Starfield session:

1. Va'ruun Penumbra: 3 quick shots, 3 held-trigger shots, one reload, one holster/draw cycle.
2. Va'ruun Starstorm: 2 short bursts, 2 long 4-6 second bursts, one reload, one holster/draw cycle.
3. Quit Starfield normally.

Expected root:

`Data/SFSE/Plugins/StarfieldDualSenseDiagnostics/v0.3.47/ShatteredSpaceWemCapture`

The root must contain `manifest.tsv` plus weapon/action/event subdirectories. Runtime log lines for captured media include `capture=written` or `capture=exists-same` and `captureFile=...`.

Zip the entire `ShatteredSpaceWemCapture` directory and send it together with the fresh StarfieldDualSense log.
