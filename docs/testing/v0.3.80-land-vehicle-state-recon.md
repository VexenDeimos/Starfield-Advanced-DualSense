# v0.3.80 Land Vehicle State Recon — Hardware Recon

This build is **diagnostic-only for land vehicles**. It intentionally adds **no** REV-8 haptics, adaptive-trigger behavior, controller-speaker playback, lightbar behavior, control changes, or vehicle physics changes.

## What the r1 safety build is trying to prove

The original v0.3.80 build used a legacy executable RVA for `VehicleDriverEnterExitEvent`. That RVA is not version-independent, so r1 disables the direct getter completely. CommonLibSF `PlayerCamera::kVehicle` remains corroboration-only and may arm the existing Wwise PostEvent correlation window, but no raw driver-event payload is captured in r1.

Expected startup lines include:

```text
Land vehicle recon: ACTIVE source=disabled-unversioned-legacy-rva rawPayloadBytes=64 rawEventCapture=off camera=kVehicle-corroboration-only identityPromotion=none Wwise=existing-PostEvent-capture diagnostic-only controllerOutput=none
Land vehicle recon: VehicleDriverEnterExitEvent source disabled reason=unversioned-legacy-rva legacyDirectGetter=no cameraFallback=yes behavior=passive-read-only controllerOutput=none
```

The important safety contract is that Starfield must reach the main menu normally without calling any legacy land-vehicle event-source RVA.

## Test sequence

Use one clean REV-8 session. Do each action for a few seconds where practical so the log has clear correlation windows.

1. Stand on foot near the REV-8 for several seconds.
2. Enter the driver seat and remain idle.
3. Drive gently forward, then full forward.
4. Brake to a stop.
5. Reverse.
6. Perform horizontal boost.
7. Perform vertical boost/jump and remain airborne briefly.
8. Land normally.
9. Drive over visibly rough terrain or small rocks.
10. Make one controlled low-speed collision and one harder safe in-game collision.
11. Perform a sharp turn/skid attempt.
12. Stop, idle, exit the vehicle, remain on foot for several seconds, then quit normally.

## What to send back

First, confirm Starfield reaches the main menu and remains stable for at least 15 seconds. If it does, run the vehicle sequence above and send the complete fresh `StarfieldDualSense` log. The useful lines begin with `Land vehicle recon:` and, in r1, should show `cameraVehicle` transitions plus Wwise correlation while `rawEventCapture=off`.

Do not judge land-vehicle controller feel in this build; `controllerOutput=none` is the correct result. Raw `q0`-`q7` driver-event evidence is intentionally unavailable until we have a current-runtime-safe event source.
