# v0.3.37 Batch 1 Speaker Validation + Batch 2 One-Pass Discovery

v0.3.37 adds controller-speaker weapon audio for all 15 Batch 1 weapons and simultaneously collects one-pass exact Wwise event/media evidence for the 10 Batch 2 weapons. Startup name scanning remains disabled.

Keep `DebugLogging = true`, `ControllerSpeaker = true`, and `SpeakerWeapons = true` for this combined validation/discovery run.
