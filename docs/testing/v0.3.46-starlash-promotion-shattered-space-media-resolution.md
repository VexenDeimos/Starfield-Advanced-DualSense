# v0.3.46 Starlash Promotion + Shattered Space Media Resolution

## Purpose

This release has two bounded goals:

1. Promote Va'ruun Starlash as a logical profile that explicitly shares the Equinox physical speaker-audio family proven by the v0.3.45 hardware log.
2. Extend the diagnostic resolver to index `ShatteredSpace - Main01.ba2` and `ShatteredSpace - Main02.ba2`, while keeping vanilla `Starfield - WwiseSounds*.ba2` archives first in lookup priority.

Penumbra and Starstorm remain discovery-only. Do not judge their final controller-speaker behavior in this build; the objective is to resolve their exact DLC media.

## Hardware discovery run

Leave Starlash alone except for one quick sanity shot if desired; its audio mapping is already promoted. Focus the log on the two unresolved DLC weapons.

### Va'ruun Penumbra

- Draw once.
- Fire 3 short trigger pulls.
- Fire 3 longer held-trigger launches, fully releasing R2 between each.
- Reload twice.
- Holster and draw once more.

The log should now resolve the exact player-object fire/draw/holster/reload events to media in `ShatteredSpace - Main01.ba2` or `ShatteredSpace - Main02.ba2` instead of `status=not-found ... media=0`.

### Va'ruun Starstorm

- Draw once.
- Fire 3 short bursts.
- Fire 3 long bursts of roughly 4-5 seconds, fully releasing R2 between bursts.
- Reload twice.
- Holster and draw once more.

We are specifically looking for whether the observed player event set resolves into a start/loop/stop family, rotating one-shots, simultaneous layers, or a hybrid. Do not infer this from event timing alone; promote only after the resolved WEM names are visible.

## Runtime acceptance checks

Startup should show:

- `StarfieldDualSense 0.3.46-starlash-promotion-shattered-space-media-resolution`
- `Weapon SFX discovery: ACTIVE ... batch=5-shattered-space-media-resolution operatorTargets=2`
- `Weapon audio pipeline: worker started families=43 profiles=47 discoveryTargets=2`
- `Weapon speaker family: profile=Va'ruun Starlash family=Equinox mode=explicit-shared`
- speaker cache startup completes with **43/43 families, 47/47 profiles, 444/444 variants, failedFamilies=0**

The Penumbra and Starstorm resolved-media lines should identify one of the two Shattered Space main archives. Existing promoted vanilla weapon media should continue resolving from the same Starfield Wwise archives as before.
