# v0.3.83 REV-8 Authority + Physics State

v0.3.83 promotes the hardware-validated `PlayerCharacter -> currentProcess -> middleHigh -> occupiedFurniture` reference to Tier-A land-vehicle identity only while `CameraState::kVehicle` corroboration is active. The camera state does not itself authorize vehicle output. A missing or invalid occupied-furniture reference fails closed and clears authority.

World-position finite differences remain the motion source. A portable physics state machine now identifies airborne ascent, descent, and touchdown. Touchdown requires substantial upward vertical motion, then substantial downward vertical motion, then a return to near-zero vertical speed. This prevents the previously observed `0xDC42D80F` pre-apex contact event from becoming false touchdown authority.

`0xDC42D80F` is retained only as contact/suspension corroboration. `0xA3BB6A5E` is explicitly non-touchdown terrain/contact evidence. Wwise never authorizes touchdown. The hardware-observed REV-8 gun signature (`VehicleFireWeapon` + `0x3DD3DADD`) and vertical boost signature (`VehicleVertBoost` + `0xF6A67354`) remain frozen.

No REV-8 haptic, adaptive-trigger, controller-speaker, lightbar, handling, physics, or control output is introduced in this build.
