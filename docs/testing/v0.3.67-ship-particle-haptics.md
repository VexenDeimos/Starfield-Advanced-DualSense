## Scope

v0.3.67 promotes only the hardware-proven Proton Beam signature captured in the v0.3.66 isolated W0/R2 run.

Authoritative firing identity:

- event: `0xC8BBBCEA`;
- first-shot ordering: Wwise can precede the first qualifying physical R2 sample by roughly 90-110 ms;
- held-fire cadence: same event on the same learned weapon-scoped Wwise object, roughly 419-434 ms between native posts;
- first-shot forward-correlation window: 180 ms;
- duplicate suppression: 20 ms;
- physical R2 threshold: 24.

The following v0.3.66 observations are **not** particle fire authority:

- `0x26DC4340` — generic object `0x3` companion heartbeat;
- `0xFAC3F34A` — sparse/release-side companion event;
- `0x1933CE84` — multi-object secondary fan-out;
- `0xBE75927E` — late multi-object secondary cluster.

No guessed RPM or synthetic particle timer exists. Every promoted pulse requires a real `0xC8BBBCEA` Wwise post plus the bounded R2/pilot gate.

## Controller feel

Each confirmed Proton Beam heartbeat produces:

- one 60 ms `ShipParticlePulse` at 0.70 base gain;
- 92 Hz tactile body + 272 Hz crack + 410 Hz charge edge;
- no continuous particle haptic layer;
- one 60 ms finite R2 `EffectEx` energy break, followed by the generic cockpit wall.

At default haptic strength, the portable waveform measurement is approximately:

- accepted laser crest: 0.141 actuator RMS;
- Proton Beam particle pulse: 0.220 actuator RMS;
- accepted ballistic cannon kick: 0.317 actuator RMS.

The intended feel is therefore a distinct energetic **WHIP**: stronger/denser than the laser pulse crest, but clearly less mechanical and less heavy than ballistic recoil.

Particle fire layers over existing propulsion. A particle takeover clears any stale laser continuous overlay rather than allowing the two weapon-family textures to leak together.

## Frozen accepted baselines

- ballistic: v0.3.63-r6 exact `0x490502BD`, 180 ms first-shot forward correlation, same-object held-fire native heartbeat, accepted trigger/haptic behavior;

The v0.3.66 particle recon probe remains source-retained but is disabled in production. Missile and EM ship families remain inert.

1. Enter pilot context and let propulsion settle.
2. Tap R2 once, wait about 1 second, then tap again.
3. Hold R2 for about 3 seconds and release.
4. Hold R2 again for about 3 seconds and release.
5. Open DataMenu while piloting, wait briefly, close it, and fire one final short burst.

- R2 should give a brief energetic break on each confirmed shot, then return to the generic cockpit wall;
- propulsion should remain underneath the pulse;
- DataMenu should mute ship output and stale particle authority must not return on close;
- laser and ballistic behavior should remain unchanged if tested afterward.
