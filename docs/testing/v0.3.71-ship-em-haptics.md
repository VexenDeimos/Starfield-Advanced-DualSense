## Scope

## Controller feel

Each confirmed EM discharge produces exactly one 60 ms `ShipEMPulse` at 0.50 base gain. The shape is deliberately light and electrical: a small 126 Hz tactile body supports a 338 Hz zap and 515 Hz crackle. It layers over normal propulsion and does not create a continuous EM vibration while R2 is merely held.

R2 receives one finite 60 ms high-frequency `EffectEx` electrical break per confirmed native discharge. It is intentionally lighter than the accepted Proton Beam break, then the generic cockpit resistance wall returns between shots.
