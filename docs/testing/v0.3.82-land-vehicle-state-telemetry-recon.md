# v0.3.82 REV-8 State / Telemetry Recon

This build is diagnostic-only for land vehicles. It does **not** add REV-8 haptics, adaptive-trigger behavior, controller-speaker playback, lightbar behavior, or vehicle-control changes.

## What changed

- Keeps `RE::CameraState::kVehicle` as correlation/suppression context only.
- Resolves the player's live `AIProcess::middleHigh->occupiedFurniture` handle through CommonLibSF while `kVehicle` is active.
- Logs the resolved reference FormID, base FormID/type, and whether the base form is `FURN` as a hardware-validation identity candidate.
- Samples that reference's world position every 100 ms and derives bounded finite-difference translational speed, vertical speed, and scalar acceleration.
- Resets motion history on identity changes, invalid samples, loading, ship takeover, and vehicle exit.
- Freezes the hardware-observed REV-8 action signatures from v0.3.81:
  - gun: `VehicleFireWeapon` + Wwise `0x3DD3DADD`
  - vertical boost/jump: `VehicleVertBoost` + Wwise `0xF6A67354`
- Keeps Wwise `0xDC42D80F` and `0xA3BB6A5E` as touchdown candidates only and appends the latest motion telemetry to those candidate log lines.

## Hardware test

1. Start on foot and wait about 5 seconds.
2. Enter the REV-8 and sit completely still for about 5 seconds.
3. Drive forward for about 5 seconds, release the stick until the REV-8 stops, then reverse for about 5 seconds and stop again.
4. Perform exactly three vertical boost/jumps. Let the REV-8 fully land and settle between each jump. Do not fire the gun or press L2 during these three jumps.
5. After the third landing, remain completely still for about 5 seconds.
6. Fire exactly one single REV-8 gun shot as a retained signature sanity check.
7. Exit the REV-8, remain on foot for about 5 seconds, then quit Starfield normally.
8. Send the complete fresh `StarfieldDualSense(...).log`.

## What should be visible in the log

- On vehicle entry, one line beginning `Land vehicle telemetry: IDENTITY source=AIProcess.occupiedFurniture`.
- The identity line should keep the same `ref=` value for the full REV-8 session and should ideally report `baseIsFurniture=yes`.
- The periodic land-vehicle state line should show `occupiedCandidate=yes` while in the REV-8.
- `speed` should remain near zero while stationary and rise while driving.
- `verticalSpeed` should become positive/negative during a jump arc rather than remaining permanently zero.
- `0xF6A67354` should still classify as `vertical-boost-hardware-observed`.
- `0x3DD3DADD` should still classify as `gun-fire-hardware-observed`.
- Any `0xDC42D80F` / `0xA3BB6A5E` line should include `telemetryRef=`, `speed=`, `verticalSpeed=`, and `acceleration=` for touchdown correlation.
- `provenVehicleIdentity=no` / production authority remains fail-closed in this build.
- No new REV-8 controller effect should be felt.

## Stop conditions

Do not promote the occupied-furniture candidate to production vehicle authority if the reference changes unexpectedly during one uninterrupted REV-8 session, the base form is not furniture, position samples are not coherent, or the telemetry remains unrelated to actual movement. Do not promote either touchdown candidate unless the jump-only run shows repeatable temporal agreement with the end of downward motion / landing.
