- ProductVersion: `0.3.65.0`
- FileVersion: `0.3.65.0`

## Scope

r2 is a tactile-only correction to the accepted v0.3.65 pulse-laser implementation. The first hardware run confirmed that exact event `0xCE7B2EB1` was being authorized, the 250 ms laser lease was refreshing/expiring, release revoked the stream, and the smooth laser R2 wall reached hardware. The missing sensation was therefore not an authority problem.

This build changes only the haptic presentation:

- continuous laser overlay: `0.55` base gain, 114 Hz body + 330 Hz electrical edge, mixer amplitude factor `0.30`;
- per-native-heartbeat crest: 40 ms `ShipLaserPulseCrest`, `0.55` base gain, 114 Hz body + 248 Hz edge + 365 Hz shimmer;
- focused crest acceptance: 0.12-0.16 actuator RMS at 48 kHz/default strength;
- standalone continuous overlay acceptance: >0.08 actuator RMS;
- one bounded `Ship laser haptics: stage=submitted ...` line per authorized heartbeat after both haptic submissions succeed.

The following remain frozen:

- exact laser Wwise event `0xCE7B2EB1`;
- 180 ms Wwise-first first-shot correlation;
- same-event/same-game-object held-R2 native heartbeat stream;
- 250 ms lease;
- physical R2 release and DataMenu/PauseMenu hard revocation;
- loading/pilot invalidation, exit, and shutdown clears;
- smooth laser adaptive-trigger resistance;
- accepted v0.3.63-r6 ballistic behavior;
- no raw-R2-only fire and no synthetic laser cadence.

## Focused hardware test

Use the same isolated pulse laser on W0/R2. Do not fire the other weapon groups during the focused run.

1. Enter pilot context and verify the normal propulsion texture and generic cockpit R2 wall.
2. Tap R2 once. Expect one clearly tactile but non-ballistic laser pulse.
3. Hold R2 for 2-3 seconds. Expect a continuous energized texture with distinct pulse crests tracking the native visual/audio pulse cadence.
4. Release R2. Laser-specific vibration and firing resistance must stop immediately; propulsion may remain.
5. Hold again for 2-3 seconds and verify clean reacquisition.
6. Open DataMenu, then close it. Ship output must mute immediately and stale laser state must not return by itself.
7. Fire one final short burst after closing DataMenu.
8. Optional: swap back to the accepted ballistic W0/R2 setup and verify r6 feel remains unchanged.

## Expected delivery evidence

Each authorized laser heartbeat that successfully reaches both haptic paths should add:

```text
Ship laser haptics: stage=submitted continuousSubmitted=yes crestSubmitted=yes overlayGain=0.550 crestGain=0.550 eventWhenUs=...
```

If the laser fire authorization lines appear but this delivery line does not, investigate the haptic backend/submission path rather than the Wwise gate.

## Hardware acceptance

Accept r2 only if the pulse crest is plainly perceptible on hardware, the continuous laser texture is distinguishable from propulsion without feeling ballistic, pulse timing follows the native laser cadence, release/menu behavior remains immediate, and the accepted ballistic path still feels unchanged.
