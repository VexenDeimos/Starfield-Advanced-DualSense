# v0.3.81 Land Vehicle Labeled Recon

Runtime target: Starfield 1.16.244.0  
Expected DLL ProductVersion/FileVersion: **0.3.81.0 / 0.3.81.0**

This build remains diagnostic-only for land vehicles. It adds no REV-8 haptic,
adaptive-trigger, speaker, lightbar, handling, physics, audio, or control output.
`kVehicle` remains corroboration/suppression context only and is not promoted to
vehicle identity authority.

## What is new

- Physical R2 samples are timestamped while the REV-8 correlation window is active.
- Starfield `ButtonEvent` semantics are compactly logged while that window is active,
  including event name, active/release edge, analog value, held duration, and device.
  This is intended to discover the game-side names used for L2 slow-time,
  left-stick movement, and boost/jump without guessing controller mappings.
- Six hardware-observed high-frequency vehicle Wwise families are aggregated into
  one-second count summaries instead of consuming the log one event at a time.
- Rare Wwise events remain individually visible. No event is promoted to a gameplay
  meaning merely because it correlates with a labeled input.

## Hardware recon sequence

Once the Windows build/install gate passes:

1. Start on foot for ~5 seconds.
2. Enter the REV-8 and idle for ~5 seconds.
3. Move forward with the left stick for ~5 seconds, release to neutral, then reverse.
4. Tap L2 slow-time three times with ~2 seconds between taps.
5. Fire exactly three single R2 gun shots with ~2 seconds between shots.
6. Perform exactly three boost/jump activations with ~3 seconds between them.
7. After the final boost/jump, remain still for ~5 seconds.
8. Exit the REV-8 and remain on foot for ~5 seconds.
9. Quit normally and provide the complete fresh StarfieldDualSense log.

The spacing is intentional: it lets input annotations be matched against rare Wwise
posts without converting controller input into authority.
