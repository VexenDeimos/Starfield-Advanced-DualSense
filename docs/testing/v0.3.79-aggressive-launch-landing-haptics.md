# v0.3.79 Aggressive Launch/Landing Haptics — Hardware Gate

## Scope

v0.3.79 retunes only the already-verified ship launch/landing presentation. Authority still comes from the existing launch/landing recon and precision-touchdown lifecycle; raw controller input never starts a transition.

- Transition body: `ShipBoost`, gain `1.00`, level `1.00` for both takeoff and landing.
- Transition triggers: sustained symmetric `EffectEx` on L2 + R2. The v0.3.79 implementation uses start position `64`, force envelope `220/255/210`, frequency `24`, and `keepEffect=true`, scaled by the existing `TriggerStrength` setting.
- Takeoff start: active pilot + fresh landed/non-docked state + `FaderMenu` open while `TakeoffMenu` is closed.
- Takeoff lifetime: the body/triggers continue through `landed=true -> false` and through the first `FaderMenu` close. They stop on the next new `FaderMenu` open edge after that first close. `LoadingMenu` after the first close is a fallback stop, and a 30-second cap prevents a stale transition.
- Landing start: the existing precision touchdown tail becomes active after the landing cinematic/load lifecycle.
- Landing lifetime: full transition body/triggers remain active until the authoritative `landed=false -> true` touchdown boundary.
- Touchdown: transition body/triggers release first, then the accepted v0.3.77 `ShipTouchdownThump` fires once at 100 ms / 0.90 gain, unchanged.
- Blocking `DataMenu`/`PauseMenu`: both transition triggers and continuous transition body hard-mute. Closing the final blocking menu restores them only if the transition is still active.
- After sequence stop: L2 returns neutral; R2 restores the existing cockpit primary-fire wall when pilot authority remains, otherwise R2 is neutral.
- No controller-speaker or lightbar changes.

## One-pass hardware check

1. Run the supplied v0.3.79 Windows gate and require PASS before launching Starfield.
2. With the wired DualSense, confirm startup marker `0.3.79-aggressive-launch-landing-haptics`.
3. From a landed, non-docked ship, take off normally. The transition should feel dramatically heavier than v0.3.78: full ShipBoost body plus strong pulsing on both L2 and R2.
4. Pay attention at liftoff. The effect must **not** disappear when `landed` changes true to false. It must also survive the first takeoff `FaderMenu` close.
5. Confirm it ends at the next takeoff transition boundary (`FaderMenu` re-open; `LoadingMenu` is the fallback) and does not remain stuck in ordinary flight. L2 should release; R2 should return to the normal cockpit wall.
6. Land at a location that produces the full visible landing cinematic. The same aggressive ShipBoost + both-trigger texture should run during the descent/tail.
7. At touchdown, confirm the sustained transition ends and the existing single heavy touchdown thump still fires once. There must be no extra synthetic thump and no stuck trigger.
8. Remain seated for about five seconds after landing and confirm normal cockpit trigger behavior is restored.
9. Quit normally and save the resulting `StarfieldDualSense(...).log`.

## Expected log evidence

Successful takeoff should include lines equivalent to:

```text
Ship launch/landing haptics: stage=start phase=takeoff body=ShipBoost gain=1.000 level=1.000 triggers=both-EffectEx-sustained
Ship launch/landing haptics: takeoff-boundary-observed action=continue-until-next-transition-boundary
Ship launch/landing haptics: takeoff-first-fader-closed action=continue
Ship launch/landing haptics: stage=stop phase=takeoff reason=takeoff-next-fader-open triggers=release
```

`takeoff-loading-fallback` is also valid if the next observed transition boundary is `LoadingMenu`. `takeoff-timeout` is a fail-safe and should not be the normal completion path.

Successful landing should include lines equivalent to:

```text
Ship launch/landing haptics: stage=start phase=landing body=ShipBoost gain=1.000 level=1.000 triggers=both-EffectEx-sustained
Ship launch/landing haptics: landing-touchdown-observed action=landing-sequence-end
Ship launch/landing haptics: stage=stop phase=landing reason=landing-sequence-end triggers=release
Ship touchdown haptics: stage=submitted kind=ShipTouchdownThump gain=0.900 ...
```

Send the fresh log plus four feel notes: takeoff body strength, takeoff trigger feel, landing body/trigger feel, and whether touchdown still produced exactly one distinct thump.
