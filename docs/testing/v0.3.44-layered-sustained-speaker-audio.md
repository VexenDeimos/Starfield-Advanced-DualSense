# v0.3.44 - Layered Sustained Speaker Audio

## Scope

v0.3.44 is a focused correction to the v0.3.43 Arc Welder/Cutter sustained controller-speaker path. Hardware testing showed that consecutive trigger pulls cycled through audibly different sustained sounds because the three discovered primary player loop files were being treated as alternate variants. In v0.3.44, all three primary `*_LP_01` loop files for the active sustained weapon are submitted together as one logical persistent voice.

Each persistent layer has its own immutable PCM reference, cursor, and loop-resume frame. The mixer advances and wraps each layer independently, then sums the layers before the existing output clamp. Trigger-press and trigger-release transients remain finite round-robin variants.

The v0.3.43 lifecycle is frozen: Arc Welder `Loop_Play=0xBB87C268` / `Loop_Stop=0x46C5B7DA`, Cutter `Loop_Play=0x8EDCB1C7` / `Loop_Stop=0x40FF9B15`, player object `0x2`, zero external sources, raw-R2 start-no-authority, and all existing pause/menu/swap/disconnect/shutdown clearing behavior remain unchanged.

Expected catalog: **46 logical profiles / 43 physical families / 444 physical variants**. No `Beam_Cross_*_LPM` helper layers are promoted in this correction.

## Focused hardware acceptance

### Arc Welder

1. Equip Arc Welder.
2. Perform at least six separate 2-3 second trigger holds. The held arc body should sound like the same complete sound every time instead of cycling through three noticeably different bodies.
3. Do one 8-10 second hold. All layers must remain continuous without gaps, repeated attack transients, or obvious loop-boundary clicks.
4. Release. The layered body must stop immediately and exactly one release transient should play.
5. Start firing, pause while R2 remains held, then unpause. Audio must stop on pause and must not resume until a fresh real `Loop_Play` occurs.

### Cutter

1. Equip Cutter.
2. Perform at least six separate 2-3 second trigger holds. The sustained body must no longer follow the prior A -> B -> C -> A pattern.
3. Do one 8-10 second hold. The three independently sized source layers must remain continuous without drift, gaps, or stacking.
4. Release and confirm immediate stop plus one release transient.
5. Start firing and weapon-swap while R2 is held. The complete layered voice must clear immediately.
6. If practical, hold through normal Cutter energy interruption and confirm the real Wwise stop ends controller audio while R2 remains physically held.
7. Quit Starfield normally and preserve the new `StarfieldDualSense` log.

## Runtime log contract

Startup must show `StarfieldDualSense 0.3.44-layered-sustained-speaker-audio`, `loopMode=layered-stems`, `families=43 profiles=46 discoveryTargets=0`, and final cache readiness of `43/43` families, `46/46` profiles, and `444/444` variants with zero failed families.

Each accepted Arc Welder/Cutter sustained start should log `layers=3` and all three media IDs under one generation. There must be no per-trigger `variant=01/02/03` selection for the sustained body. Stop events must still clear the one logical generation using the existing exact Wwise stop events.
