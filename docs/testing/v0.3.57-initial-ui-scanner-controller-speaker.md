# v0.3.57 Initial UI + Scanner Controller Speaker — Windows and Hardware Acceptance

## Prerequisite

The Windows/MSVC gate must complete first and the installed DLL version check must report both `ProductVersion` and `FileVersion` as **0.3.57.0**. Do not use a runtime log from a different DLL version as v0.3.57 acceptance evidence.

## Hardware procedure

1. Set `ControllerSpeaker = true`, `SpeakerScannerUI = true`, and `DebugLogging = true` for evidence.
2. Launch Starfield through SFSE, load a save, and wait for the UI/scanner readiness lines from the background audio-preparation worker before testing.
3. Navigate ordinary menus one step at a time. Verify the controller speaker mirrors `UIMenuGeneralFocus` while Starfield's normal menu audio remains audible in the game mix.
4. Hold the stick or D-pad for rapid navigation. Judge the native-exact repeated focus cadence. v0.3.57 deliberately has no debounce, deduplication, replacement, or held-navigation limiter.
5. Perform OK/accept actions several times. Verify the controller speaker mirrors `UIMenuGeneralOK`.
6. Perform Back/cancel actions several times. Verify the controller speaker mirrors `UIMenuGeneralCancel`.
7. Open the scanner. Verify the controller speaker mirrors `UIMenuMonocleOpen`.
8. Close the scanner. Verify the controller speaker mirrors `UIMenuMonocleClose`.
9. Confirm Starfield's normal UI/scanner audio is still present in the normal game mix. The controller layer is additive only.
10. Set `SpeakerScannerUI = false`, relaunch, and repeat representative focus/OK/cancel/scanner actions. Verify all five controller copies are absent while enabled weapon/comms speaker categories remain unaffected.
11. Restore `SpeakerScannerUI = true`, set `ControllerSpeaker = false`, relaunch, and verify the master controller-speaker output is disabled.
12. Restore the normal config. Verify one known-good weapon controller-speaker case, remote VO, haptics, adaptive triggers, lightbar, touch shortcut, and a clean normal shutdown.

## What to report

Please report the runtime log plus separate qualitative notes for:

- rapid-focus chatter/cadence;
- overall UI-speaker loudness;
- whether Focus/OK/Cancel durations feel appropriate;
- whether fast scanner open/close overlap sounds natural or messy;
- tonal balance and intelligibility through the DualSense speaker;
- confirmation that normal Starfield UI/scanner audio stayed present.

Do **not** compensate for any of those observations by pre-tuning v0.3.57. This build intentionally uses the native decoded amplitude, full duration, and Starfield's exact focus cadence so later tuning can be based on hardware evidence.
