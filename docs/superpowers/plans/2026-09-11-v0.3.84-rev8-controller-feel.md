# v0.3.84 REV-8 Controller Feel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the first production REV-8 DualSense presentation—subtle telemetry-driven chassis haptics, boost/landing/gun haptics, mounted-gun R2 behavior, and `VehicleAim` L2 resistance—without weakening the frozen v0.3.83-r1 authority/physics baseline or changing accepted ship/on-foot behavior.

**Architecture:** Keep authority and game-state truth in `GameStateAdapter`/`Plugin`, publish one compact trusted `LandVehicleMotionState` for continuous presentation, and emit explicit production `GameEventType` semantics for finite actions. `HapticsManager` owns REV-8 continuous/finite haptic presentation; `EffectsEngine` owns REV-8 adaptive triggers. Existing `LandVehicleContextEntered/Exited` remains suppression-only and must never acquire production REV-8 effects by itself.

**Tech Stack:** C++23, CommonLibSF/SFSE, existing `GameEvent` router, existing DualSense `EffectsEngine`, `HapticsManager`, `HapticMixer`, Xmake, Python source-contract regressions, portable GCC/Clang focused tests, Windows/MSVC hardware gate.

**Spec:** `docs/superpowers/specs/2026-09-11-v0.3.84-rev8-controller-feel-design.md`

## Global Constraints

- Baseline is **v0.3.83-r1 Boost-Armed Physics Correction**.
- New release version is **0.3.84**; expected ProductVersion/FileVersion are **0.3.84.0 / 0.3.84.0**.
- Runtime marker is exactly **`0.3.84-rev8-controller-feel`**.
- Tier-A REV-8 authority remains `AIProcess.occupiedFurniture` validated as furniture while `RE::CameraState::kVehicle` is corroboration/suppression only.
- `LandVehicleContextEntered/Exited` remain suppression/lifecycle events; neither event may install REV-8 production output.
- Frozen boost authority remains Wwise **`0xF6A67354`** under current Tier-A authority.
- Frozen gun Wwise identity remains **`0x3DD3DADD`**, and production gun fire requires current `VehicleFireWeapon` semantic correlation under Tier-A authority.
- Frozen slow-time input identity remains Starfield semantic **`VehicleAim`**.
- Frozen jump/touchdown authority remains boost-armed physics; terrain alone cannot authorize AIRBORNE/DESCENDING/TOUCHDOWN.
- `0xDC42D80F` remains contact/suspension corroboration only; `0xA3BB6A5E` remains non-touchdown terrain contact.
- No REV-8 speaker or lightbar behavior in v0.3.84.
- No vehicle handling, physics, audio, control, memory-write, or synthetic gameplay-state changes.
- No synthetic gun cadence or synthetic jump/landing timers.
- Existing ship and handheld controller behavior is frozen except for generic arbitration needed to recognize active Tier-A REV-8 production ownership.
- Loading, blocking menus, authority loss, identity/epoch change, vehicle exit, ship takeover, and shutdown fail closed to neutral REV-8 output; no cached output is restored afterward.
- Package only files actually changed by v0.3.84; do not repackage the whole project.

const float speed01 = std::clamp(state.speed / kSpeedFullScale, 0.0F, 1.0F);

float target = 0.0F;

const float impact = std::clamp(std::fabs(impactVerticalSpeed), 3.0F, 25.0F);
